# RAG-система для аналізу фінансових звітів

Навчальний проєкт з побудови простої RAG-системи для пошуку відповідей у
фінансових даних компаній за 2024 рік. Система розбиває дані на окремі
документи, зберігає їхні векторні представлення у Chroma та формує відповіді
українською мовою за допомогою LLM.

## Стек

- Python 3.10+
- Jupyter Notebook
- LangChain
- Chroma
- OpenRouter API
- `openai/text-embedding-3-small` для embeddings
- `openai/gpt-4o-mini` для генерації відповідей

## Структура проєкту

```text
.
├── yevhen_petrov_ДЗ7.ipynb  # основний notebook із реалізацією RAG
├── .env                      # локальний API-ключ, не додається до Git
└── .gitignore
```

## Як запустити

1. Створіть і активуйте віртуальне середовище:

   ```bash
   python -m venv .venv
   ```

   Windows PowerShell:

   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

2. Встановіть залежності:

   ```bash
   pip install jupyter python-dotenv langchain-text-splitters \
       langchain-openai langchain-chroma
   ```

3. Створіть файл `.env` у корені проєкту та додайте ключ OpenRouter:

   ```env
   OPENROUTER_API_KEY=your_api_key_here
   ```

4. Запустіть Jupyter:

   ```bash
   jupyter notebook
   ```

5. Відкрийте `yevhen_petrov_ДЗ7.ipynb` і виконайте комірки послідовно.

## Як працює система

1. Вхідні дані містять фінансові показники чотирьох компаній.
2. `RecursiveCharacterTextSplitter` створює 4 чанки, по одному на компанію.
3. Для кожного чанка додаються метадані `kompaniya` та `rik`.
4. `Chroma` створює векторне сховище фінансових звітів.
5. Retriever повертає 2 найбільш релевантні документи (`k=2`).
6. RAG-ланцюг передає знайдений контекст у `gpt-4o-mini`.
7. Prompt обмежує відповідь наданим контекстом і забороняє вигадувати дані.

## Приклади запитів

- Яка виручка у компанії ТехНова Інк за 2024 рік?
- Скільки працівників у ГрінЕнерджі Солюшнс?
- Який показник ROE у РітейлМакс Груп?
- Де знаходиться штаб-квартира ТехНова Інк?
- Яка маржа EBITDA у ФінТех Дайнамікс?

Для компанії, якої немає у вхідному контексті, система повертає повідомлення,
що інформація відсутня, замість вигаданої відповіді.

## Результат перевірки

Notebook перевіряє шість тестових запитів: п'ять запитів щодо наявних компаній
та один запит щодо невідомої компанії. Для відомих компаній повертаються
конкретні фінансові показники, а для невідомої — коректне повідомлення про
відсутність даних.

## Безпека

виключені з контролю версій через `.gitignore`.
